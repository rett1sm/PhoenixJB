# Phoenix JB 0.00 · Beta

**Phoenix JB** — экспериментальный центр управления приложениями и jailbreak-ресурсами для iPhone.

## Возможности беты
- обновлённый тёмный интерфейс;
- обзор устройства и состояния среды;
- выбор Sileo или Zebra;
- локальная библиотека IPA;
- импорт IPA из приложения «Файлы»;
- загрузка IPA по прямой ссылке;
- удаление файлов из библиотеки;
- добавление и хранение адресов репозиториев.

## Что пока в разработке
- настоящий jailbreak, эксплойт и bootstrap;
- установка Sileo, Zebra и DEB-пакетов;
- получение и разбор индексов репозиториев;
- запуск неподписанных IPA внутри Phoenix по модели LiveContainer.

IPA-файлы в текущей версии только импортируются и хранятся внутри контейнера приложения. Кнопка запуска показывает пояснение: полноценный движок запуска ещё не подключён. Сборка IPA не подписана.

## Версии
Текущий канал — **Beta**. Номер версии приложения: `0.00`.

Следующие тестовые выпуски: `0.01`, `0.02`, `0.03` и далее.

## Сборка
Каждый push в `main` запускает сборку в GitHub Actions. Готовый IPA прикладывается к предварительному выпуску во вкладке [Releases](https://github.com/rett1sm/PhoenixJB/releases).
