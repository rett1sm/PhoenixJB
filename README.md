# Phoenix JB — SwiftUI preview

Это исходный проект интерфейса Phoenix JB для iPhone. Для сборки не нужен собственный Mac: GitHub Actions собирает приложение на облачном macOS runner.

## Что уже работает
- тёмный интерфейс с вкладками «Главная», «Каталог», «Источники», «Настройки»;
- выбор Sileo или Zebra с локальным сохранением выбора;
- добавление и удаление URL-источников с локальным сохранением;
- отображение версии iOS через системный API.

## Что пока не реализовано
- jailbreak exploit / boot chain / bootstrap;
- установка Sileo или Zebra;
- загрузка индексов репозиториев и установка deb-пакетов;
- установка IPA из каталога.

Это интерфейс-прототип, а не jailbreak. На iPhone 11 с iOS 27.2 пока нет подтверждённого простого IPA-метода, который можно честно встроить как рабочую кнопку.

## Сборка без Mac с Windows
1. Создай аккаунт на GitHub, если его ещё нет.
2. Создай новый репозиторий, например `PhoenixJB`.
3. Распакуй архив и загрузи в репозиторий всё содержимое папки `PhoenixJB` (включая скрытую папку `.github`). Можно использовать веб-интерфейс GitHub: **Add file → Upload files**.
4. Открой вкладку **Actions** и выбери workflow **Build Phoenix JB IPA**. Нажми **Run workflow**. Также сборка запускается после push в ветку `main`.
5. Когда задача завершится успешно, открой её страницу и скачай artifact `PhoenixJB-unsigned-IPA`.
6. Распакуй скачанный artifact: внутри будет `PhoenixJB-unsigned.ipa`.
7. На Windows установи Sideloadly с официального сайта https://sideloadly.io/ . Подключи iPhone по USB, загрузи IPA в Sideloadly и подпиши её своим Apple ID непосредственно в Sideloadly. Никому не отправляй пароль Apple ID и не добавляй его в GitHub.
8. Для sideloading на iOS 16 и новее включи **Settings → Privacy & Security → Developer Mode**. Следуй подсказкам iPhone.

Примечания:
- GitHub Actions использует облачную macOS-машину; собственный Mac не нужен. Для публичных репозиториев стандартные GitHub-hosted runners доступны без оплаты за минуты; для приватных репозиториев действуют лимиты и тарифы GitHub Actions.
- IPA в artifact намеренно не подписан. Sideloadly выполняет подпись для твоего устройства.
- Бесплатная подпись Apple ID обычно действует 7 дней; потом приложение нужно переподписать. Лимиты и требования могут меняться — смотри актуальную документацию Sideloadly.
- Этот способ только собирает и устанавливает обычное приложение Phoenix JB. Он не выполняет jailbreak и не включает системные твики без совместимого jailbreak-backend.

## Локальная сборка на Mac
Открой `PhoenixJB.xcodeproj` в Xcode, выбери target `PhoenixJB` и настрой подпись в Signing & Capabilities.

Минимальная версия deployment target — iOS 16.
