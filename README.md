# Phoenix JB 0.00 — бета

Phoenix JB — экспериментальное приложение для iPhone. Проект находится в активной разработке; версия **0.00** предназначена для раннего тестирования интерфейса.

## Что есть в бете
- тёмный интерфейс на SwiftUI;
- отображение модели устройства и версии iOS;
- выбор предпочтительного менеджера пакетов: Sileo или Zebra;
- локальный список источников и репозиториев;
- сборка IPA через GitHub Actions на macOS.

## Что ещё не реализовано
- настоящий jailbreak, эксплойт и bootstrap;
- установка Sileo, Zebra и DEB-пакетов;
- загрузка индексов репозиториев и проверка совместимости пакетов;
- запуск неподписанных IPA внутри Phoenix по модели LiveContainer.

Сейчас добавление репозитория только сохраняет его URL на устройстве. IPA из GitHub Actions не подписан; для установки требуется совместимый способ подписи и установки.

## Бета-релизы
Актуальные тестовые сборки публикуются во вкладке **Releases** с пометкой предварительного выпуска. Текущий канал: [Phoenix JB 0.00 — бета](https://github.com/rett1sm/PhoenixJB/releases/tag/v0.00-beta).

Номер версии приложения задаётся в Xcode как `0.00`. Следующие тестовые сборки будут менять номер в формате `0.01`, `0.02` и далее.
